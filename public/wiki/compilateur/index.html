Compilateur

RôleTraduire le code source
PionnièreGrace Hopper
ExemplesPour le C, Rust, Go

Un compilateur est un programme qui traduit le code écrit par un humain en instructions que la machine peut exécuter.

1Compilé ou interprété

Un langage compilé, comme le C ou Rust, est traduit en entier avant d’être lancé. Un langage interprété, comme Python, est lu et exécuté au fur et à mesure. JavaScript, lui, est compilé à la volée par le navigateur.

2Les erreurs

Le compilateur refuse le code s’il trouve des erreurs, avec un message qui indique la ligne. Ses messages sont parfois cryptiques, parfois très utiles. Celui de Rust est réputé pour être particulièrement aimable.
