Code Konami

Séquence↑ ↑ ↓ ↓ ← → ← → B A
OrigineJeux Konami, années 1980
Marche iciPeut-être [réf. nécessaire]

Le code Konami est une séquence de touches devenue culte : haut, haut, bas, bas, gauche, droite, gauche, droite, B, A. Il vient des jeux vidéo de l’éditeur Konami.

Utilisé dans les projets

›_Le terminal caché

1L’histoire

Dans les années 1980, ce code de triche donnait des bonus dans plusieurs jeux Konami. Il est devenu si célèbre que beaucoup de sites et de jeux le cachent aujourd’hui comme easter egg.

2Sur ce site

Sur un ordinateur, tape la séquence avec les flèches du clavier, puis B et A. Il se passe peut-être quelque chose.

3Pourquoi il est si célèbre

Le code rendait certains jeux beaucoup plus faciles, et s’est transmis de joueur en joueur, à l’époque où Internet n’existait pas encore pour tout le monde. Il est devenu un symbole de la culture du jeu vidéo.

4Comment il marche ici

Le terminal écoute les touches du clavier. Si la séquence complète est tapée dans l’ordre, le mode fun s’active, l’écran tremble et un message apparaît. Dix touches, une ligne de JavaScript par touche ou presque.
