Le code est un ensemble d’instructions écrites pour qu’un ordinateur fasse quelque chose. Pour la plupart des gens, c’est un outil. Pour Wyatt, c’est un mode de vie.

1Définition

Coder, c’est écrire des instructions dans un langage que l’ordinateur comprend : Python, JavaScript, et bien d’autres. L’ordinateur fait exactement ce qu’on lui dit. Le problème, c’est qu’il fait exactement ce qu’on lui dit.

2Chez Wyatt

Tout a commencé en 6e, avec une tortue en Python qui dessinait un cœur. Depuis, il code des sites, des SaaS, des bots Discord et des jeux. Quand on lui demande ce qu’il fait en dehors du code, il répond : « du code ».

3Cycle de vie typique

  1. Avoir une idée à 23 h.
  2. « Juste cinq minutes. »
  3. Il est 4 h du matin.
  4. Ça marche.
  5. Ça ne marche plus.
  6. Recommencer.
