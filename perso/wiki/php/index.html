PHP

Créé parRasmus Lerdorf
Année1995
CôtéServeur
Célèbre pourWordPress

PHP est un langage de programmation qui s’exécute sur le serveur. Il fabrique les pages avant de les envoyer au navigateur. WordPress, par exemple, est écrit en PHP.

1Comment ça marche

Quand tu ouvres une page en PHP, le serveur exécute le code, va chercher des informations dans une base de données, puis envoie le résultat en HTML. Le visiteur ne voit jamais le code PHP lui-même.

2L’avis de Wyatt

Les sites de Wyatt sont statiques : pas de PHP, juste des fichiers prêts à l’emploi. Mais un jour, un SaaS aura besoin d’un serveur. Et là, on verra.
