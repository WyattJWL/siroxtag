localStorage

TypeStockage du navigateur
DuréeJusqu’à ce qu’on l’efface
Exemples iciMode fun, accord Spotify

Le localStorage est un espace de stockage dans ton navigateur. Un site peut y ranger de petites informations, qui restent même après avoir fermé l’onglet.

Utilisé dans mes projets

1Chez Wyatt

Ce site y retient si tu as activé le mode fun, ou si tu as accepté le lecteur Spotify. Ces informations restent sur ton appareil : elles ne sont envoyées à personne.

2La règle

Comme pour les cookies, ce qui n’est pas indispensable demande ton accord, et doit être expliqué dans les mentions légales. C’est fait.
