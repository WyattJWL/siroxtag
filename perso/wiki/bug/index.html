Le cache fantôme

TypeBug légendaire
LieuEn production
SymptômesRien ne plante, tout est faux
SéquellesCauchemars

Le cache fantôme en production, combiné à une erreur d’hydratation silencieuse, est le pire bug de la carrière de Wyatt. Rien ne plantait. Tout était faux.

1C’est quoi, un cache ?

Un cache garde une copie d’une page pour l’afficher plus vite. Un cache « fantôme », c’est quand cette vieille copie continue d’apparaître alors que le site a changé. On corrige le bug, mais les visiteurs voient encore l’ancienne version.

2C’est quoi, l’hydratation ?

Sur certains sites modernes, le serveur envoie d’abord une page toute faite. Ensuite, le JavaScript « hydrate » la page : il s’y accroche pour la rendre interactive. Si la page et le JavaScript ne racontent pas la même chose, c’est une erreur d’hydratation. Quand elle est silencieuse, aucun message ne prévient.

3Le cocktail

Une vieille version servie par le cache, plus un JavaScript qui ne correspond plus. Résultat : des boutons qui ne répondent pas, des textes qui changent tout seuls, et aucun message d’erreur. Le genre de bug qui fait douter de tout.
