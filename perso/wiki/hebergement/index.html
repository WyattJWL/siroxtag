Hébergement

RôleStocker et servir un site
ExemplesGitHub Pages, Vercel, OVH
PrixDe gratuit à très cher

L’hébergement est le service qui garde les fichiers d’un site sur un serveur et les rend accessibles en permanence sur Internet.

1Les types

Un site statique peut être hébergé gratuitement, comme siroxtag.fr sur GitHub Pages. Une application avec base de données a besoin d’un hébergement plus complet. Le site du bot des impôts, lui, est sur Vercel.

2Côté légal

En France, un site doit indiquer qui l’héberge dans ses mentions légales. C’est pour ça que celles de siroxtag.fr citent GitHub.
