CSS

Nom completCascading Style Sheets
Proposé en1994
RôleL’apparence
Ennemi juréCentrer une div

Le CSS est le langage qui décrit l’apparence d’une page : couleurs, polices, marges, mise en page et animations. Le HTML dit « quoi », le CSS dit « comment ça a l’air ».

Utilisé dans mes projets

1Comment ça marche

On choisit des éléments, puis on leur donne des règles : h1 { color: black; }. Le mot « cascade » vient du fait que plusieurs règles peuvent s’appliquer, et que la plus précise gagne.

2La légende

Pendant des années, centrer un élément en CSS a été une blague classique chez les développeurs. Aujourd’hui, c’est simple. Mais la blague est restée [réf. nécessaire].
